# Visual Snapshot Analysis — Generic Tenant Method

1. Resolve the tenant's business/reporting window from context before loading images.
2. Enumerate every snapshot/event in the requested window and record coverage gaps.
3. Use canonical physical cameras only.
4. Group by camera and analyze chronologically.
5. Apply only the metrics allowed by that camera role/site type.
6. Preserve source snapshot/event IDs and local timestamps for traceability.
7. Build sequences before deriving sessions, dwell, opening/closing, flows or trends.
8. Separate direct observations, derived estimates and unsupported claims.
9. Assess repeated image-quality issues before trusting analytics or recommending camera changes.
10. Build the report only after the visual pass is complete.
11. Missing evidence is unknown, never zero activity.
12. Write recommendations only from repeated evidence, confirmed configuration gaps or health failures.
