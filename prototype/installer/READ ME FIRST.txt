WatchLog — installing on your site PC
=====================================

WatchLog connects this Windows PC to the CCTV recorder already installed at
your site. Setup is graphical and normally takes only a few minutes plus local
network discovery time.

WHAT YOU NEED
-------------
  1. This PC on the SAME network as your CCTV recorder, kept switched on.
  2. Your recorder's own username and password.
  3. The one-time WatchLog site code from Settings > Sites & Setup.

You do not need port forwarding, a VPN or inbound firewall changes. WatchLog
connects outward only.


HOW TO INSTALL
--------------
  1. Run WatchLog-Setup.exe.

  2. Approve the Windows administrator prompt. WatchLog needs administrator
     access to install securely and start automatically with Windows.

  3. Follow WatchLog Setup:
       - enter the WatchLog site code,
       - let WatchLog find the recorder (or enter its local IP address),
       - enter the recorder login,
       - confirm discovered cameras and their purposes,
       - wait for WatchLog to connect the site and add its cameras.

  4. Finish only after the wizard says "WatchLog is ready". WatchLog will not
     mark setup complete when a required connection check fails.


YOUR RECORDER PASSWORD
----------------------
  - The recorder password stays on this Windows PC.
  - WatchLog protects it using Windows security after setup succeeds.
  - It is not written in plaintext to watchlog.ini.
  - Upgrades automatically move older local plaintext credentials into
    protected storage before WatchLog restarts.


AFTER INSTALLING
----------------
  - WatchLog starts automatically with Windows.
  - There is no terminal window to keep open.
  - Local support logs are stored at:
        C:\ProgramData\WatchLog\agent.log
        C:\ProgramData\WatchLog\setup.log
  - A WatchLog Start Menu folder contains setup/reconfiguration and uninstall
    shortcuts.


IF THE RECORDER IS NOT FOUND
----------------------------
  - Make sure this PC and the recorder are on the same local network rather
    than a guest Wi-Fi network.
  - Make sure the recorder is switched on and its HTTP/HTTPS web service is
    enabled.
  - Enter the recorder's local IP address manually if automatic discovery does
    not find it. The recorder's own screen normally shows this under Network.
  - Compatibility depends on recorder model and firmware. A successful setup
    verifies the recorder and cameras connected during that installation.


TO REMOVE IT
------------
  Use Windows Settings > Apps > Installed apps > WatchLog > Uninstall,
  or the Uninstall WatchLog shortcut in the WatchLog Start Menu folder.

Uninstall removes the protected recorder credential. Local support logs and
connection history are retained for support or reinstall continuity unless a
full local data wipe is requested.


PRIVACY BOUNDARY
----------------
Recorded video stays on your recorder. Recorder credentials stay on the site
PC. WatchLog sends business/event metadata and approved incident or
configuration stills required by the product. WatchLog does not provide live
camera browsing or facial recognition.
