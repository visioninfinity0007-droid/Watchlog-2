# Analytics Studio v1 release scope

## Must ship

- Site type selection and presets.
- Camera purpose classification.
- Monitoring rules with line/polygon geometry, class filters, schedules and dwell thresholds.
- Versioned agent configuration sync.
- Local analytic event generation and idempotent upload path.
- Visitor Flow, Vehicle Flow, Boundary Monitoring, Zone Activity, Schedule Monitoring and Site Health metrics.
- Portal Analytics Studio configuration and Analytics Overview.
- Installer steps for site type and camera purpose.
- Daily report analytics section.
- Tenant isolation and regression tests.

## Must not be mislabeled as complete in v1

- Exact POS/till transaction counting.
- Facial recognition or visitor identity.
- Cross-camera re-identification.
- Safety/compliance guarantees.
