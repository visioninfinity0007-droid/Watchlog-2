# Analytics Studio v1 UX

## Installer flow

1. Connect account
2. Find recorder
3. Test recorder
4. Discover cameras
5. Choose site type
6. Classify camera purposes
7. Finish hardware setup
8. Continue advanced monitoring setup in portal

## Portal flow

### Analytics overview
Shows enabled business metrics with site/date/camera filters.

### Analytics studio
Choose site → camera → purpose → monitoring pack/rules.

### Rule editor
- Select monitoring goal
- Select person/car/motorcycle classes as applicable
- Draw line or polygon on configuration still
- Configure direction/dwell
- Choose schedule
- Save and publish configuration

## Copy principles

Use business language:
- Visitor Flow, not person line-cross counter
- Vehicle Flow, not class track count
- Boundary Monitoring, not polygon trigger
- After-Hours Activity, not schedule_activity

The UI may expose technical details in an Advanced section for operators who need them.
